# Frozen BidiModule source successor: proposal only

The current authored-use checker cannot reconcile the 23 absent historical source files through a review-data change alone. `authoredUseReviewEvidence` requires a nonempty current source whose hash equals `candidate_source_sha256`, including when a review says `removed-use`. The two retained core files can use that normal physical-source check. A narrowly owned, main-only operation for exactly the 23 authenticated retired keys is needed; it must independently prove each historical source, present-day absence and the current graph. A generic removal exception, a synthetic historical source presented as current, or changing only the conclusion or hashes would be insufficient.

The exact external proposal is in `candidate-review-records.json` and `candidate-source-data.json`; `RECONCILIATION.md` gives the production-contract changes, fail-closed predicates and control plan. The draft records are explicitly **not production-valid**: the 23 missing sources have null current hashes and status `proposal-not-reviewed`. ## Boundaries

The finite operation must bind the original review, each old source and all prior direct evidence, both producer/test transitions, physical absence with safe path handling, the whole 21-family/core/root graph, current peer line and public declarations, and stable source reads. It must reject any restored or mutated path, graph, evidence, root, peer or key population. The two retained cases must continue to require their normal present-source check. Existing `additionalUseBaseline` retirement treatment retains a particular historical *additional* obligation against a present current file; it does not implement or authorize these absent frozen-path decisions.

No source, roster, validator, product, golden or existing receipt was modified. This review used Git/history, hashes, physical file inspection and package declarations; it did not run the successor, tests, browser or packed suite. Packed/native, full peer/Node/RxJS floors, upstream-SHA and G11/admission outcomes remain unqualified. A fresh final combined artifact and targeted Bidi, namespace and browser checks are separate work.
