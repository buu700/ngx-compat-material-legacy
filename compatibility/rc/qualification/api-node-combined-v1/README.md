The census compares all 512 archive members, physical extracted files, and all 22 FormField and 15 Select embedded sources to the snapshot. It records 56 changed members relative to the prior archive `877c8b62e1ea9b134d838043dda436abb4ccf9515041640fdb05dc6113727b0b`.

The prior FormField and Select source copies here were byte-compared with their prior archive source maps. The successor checks exact transformations from those sources to the candidate. This is an explicit additional lifecycle behavior, not an equivalence claim for the whole class; separate lifecycle, public-member and motion settlement is required. The historical receipt test passes independently. These tests do not exercise native/browser nodes or settle the wider factory matrix.
