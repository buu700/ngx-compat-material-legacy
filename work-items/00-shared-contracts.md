# Shared contracts before parallel component work

Create one owner for token identity/delegation, the finite historical Sass facade, and engine-free motion configuration. Use `research/legacy-core-delegation.json` and `research/sass-symbols.json` as preclassified seeds, then reconcile with generated actual exports. Do not let each component task clone its own ErrorStateMatcher/date tokens/theme parser/motion option.

Prove packaging with one simple component, then prove the risky joint boundary with legacy form-field/input/select and a current datepicker. A current public class can still expect a changed protocol. Add strict generic/interface checks rather than bypassing errors with casts.

Historical reference output remains immutable. Tests comparing Sass output must also verify component styles/runtime states; current shared infrastructure is a documented boundary, not a blanket ignore list. The implementation order is flexible, but conflicting shared contracts are not.
